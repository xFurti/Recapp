# Demo video script (60-90 s, English)

Record on a phone-sized browser window, demo class, simulated time via the clock button.

| Time | Screen | Voice-over |
| --- | --- | --- |
| 0-10 s | Landing page | "At our school, homework lives in ClasseViva, files in Classroom, notes on Campus. Nobody writes down what happened in the lab." |
| 10-20 s | Try the demo → Today (15:00) | "Recapp is one card per day, written by the classmate on duty. Today it's Leo's turn, and the app says he hasn't published yet." |
| 20-40 s | Write the day: INI lab block, "+ Test", paste "Math: ex. 12-15, test Fri" → Read with AI → drafts | "The editor already knows today's timetable. Lab hours open a lab block: goal, repo, the trap to avoid. I paste a line from ClasseViva: AI turns it into drafts, but I decide what gets published." |
| 40-50 s | Publish → Today shows "Published by leo" | "Published. The whole class sees it, with the test counting down." |
| 50-60 s | Yesterday tab → Listen | "Missed a day? Open Yesterday. You can even listen to it." |
| 60-75 s | Clock → 18:30, log in as gianni → "Take the turn" | "If nobody writes by six p.m., anyone can take over. The rotation skips weekends and school holidays." |
| 75-90 s | Class → Timetable, then School area | "Real timetables of our two classes, a read-only view for the headteacher, and no school passwords, no grades. We don't log into the gradebook: the class writes one card." |
