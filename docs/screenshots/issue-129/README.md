# Prove visive — #129

Screenshot reali acquisiti con Chromium su Linux. App React e shell reali,
risposte API simulate con dati di prova bilingui, autore e titoli lunghi e una
stringa senza spazi. Il backend non è parte di questa verifica.

Il prima è `main` allo SHA `6cc6421d909ce58fc4fd887566f326e238573cb1`,
prima delle modifiche applicative. Il dopo usa gli stessi dati e percorsi.
Viewport: 320×844, 390×844 e 1440×1000. Screenshot dell’intera pagina;
le barre fisse sono visibili nella posizione della viewport al momento della cattura.
Nel prima alcuni file sono più larghi della viewport perché la cattura integrale
include l’overflow originale dei nomi e dei testi senza spazi.
Non sono simulazioni grafiche. Il movimento è ridotto per rendere confrontabili
le catture. I file sono conservati nel repository, secondo la convenzione già
usata per le prove UI, senza scadenza dei link.

I test al 200% raddoppiano la dimensione radice del testo mantenendo la stessa
larghezza della viewport; anche i controlli in rem crescono e devono adattarsi.
Le catture al 200% sono prove aggiuntive, non confronti con un prima differente.
