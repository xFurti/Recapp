# Issue #79: prove visive

Schermate acquisite il 16 ottobre 2026 dalla build di produzione del branch, servita da FastAPI
con un database SQLite locale isolato. Le risposte HTTP non sono simulate. DEMO e classe di
prova contengono soltanto identità e contenuti fittizi.

- 01–04: telefono 390 px, italiano, chiaro; scheda Classe, serie, primo posto e parità, Grazie
  su un elemento di In arrivo.
- 05–07: desktop 1280 px, inglese, scuro; scheda Classe, classifica con regole, elementi della
  giornata con i propri Grazie.
- 08: telefono 390 px, inglese, scuro; classe senza pubblicazioni.
- 09: desktop 1280 px, italiano, chiaro; vista Contributi senza contributi.
- 10: telefono 390 px, italiano, chiaro; recuperi e contributi senza Grazie.
- 11: telefono 320 px, italiano, chiaro; contatori leggibili nella nuova disposizione.
- 12: telefono 390 px, inglese, scuro; carattere radice al 200%, con contenuti della riga
  interamente visibili. È una verifica di ridisposizione del testo, non una simulazione della
  tastiera o del pinch zoom di un dispositivo fisico.

La demo è condivisa fra le acquisizioni: il Grazie aggiunto nella schermata 04 è presente anche
nelle schermate successive, quindi le parità possono cambiare. Le ultime due immagini e le
schermate della classifica sono state ispezionate dopo le correzioni al layout.
